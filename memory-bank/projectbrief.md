# GitHub Copilot Experiment Project Brief

## Project Overview

This project is a 2-week experiment to demonstrate the value of GitHub Copilot for graduate data scientists at Lloyds Banking Group. Currently, only employees Grade D and above have access to GitHub Copilot, while graduates use Edge Copilot (browser-based). The goal is to create a compelling case with quantitative and qualitative evidence showing the business value of providing GitHub Copilot to graduates.

## Experiment Structure

### Participants
8 graduate data scientists divided into 3 project-based teams:
- Logistic Regression Project (2 grads): Hamza (lead) + Tao
- Pre-processing Project (4 grads): Luke, CJ, Maria, Josh
- ACG Project (2 grads): Rindra, David

### Timeline
- Week 1: Complete tasks using Edge Copilot
- Week 2: Complete comparable tasks using GitHub Copilot
- Total time requirement: Maximum 2 hours per graduate

### Task Categories
- Writing unit tests
- Creating simple functions
- Reviewing code
- Writing documentation/MDocs

### Key Differentiators to Test
- Integration with RS Copilot library (Risk Science standardization library)
- Code context understanding capabilities
- Character limitations in Edge Copilot
- Development environment integration vs browser context switching

## Repository Purpose

This repository serves as a collaboration tool for the experiment. It provides:
1. A structured environment for task completion
2. Templates for metrics collection
3. Analysis tools for evaluating results
4. Documentation for participants

## Success Criteria

The experiment will be successful if it provides:
1. Quantitative analysis of time/efficiency savings
2. Examples demonstrating quality differences
3. ROI calculation based on graduate hourly costs vs license cost
4. Compelling recommendation document for leadership

## Technical Considerations

- All examples should resemble banking/data science work
- Examples should follow RS Copilot standards
- Data collection should be as automated as possible
- The repository should be optimized for simplicity and low graduate time investment

## Final Deliverables

The repository should facilitate creating:
1. Quantitative analysis of time/efficiency savings
2. Examples demonstrating quality differences
3. ROI calculation based on graduate hourly costs vs license cost
4. Compelling recommendation document for leadership
